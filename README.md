# DayZ RVMAT Studio

Редактор и генератор материалов `.rvmat` для DayZ. Одно настольное приложение (tkinter), без Qt, без браузера и сервера.
ТЗ: [docs/TZ.md](docs/TZ.md).

## Установка и запуск (Windows)

1. Нужен Python 3.10+ с python.org (в нём уже есть tkinter).
2. Запустите **`start.bat`**. При первом запуске он создаёт папку `.venv` и ставит `numpy` и `Pillow` (≈ 40 МБ) и необязательный `moderngl` для GPU-рендера (≈ 1 МБ) — обычно 10–20 секунд. Дальше программа стартует мгновенно. Тесты при запуске **не** гоняются (они в `run_tests.bat`).

Из консоли: `pip install -r requirements.txt -r requirements-gl.txt && python -m rvmat_studio`.
CLI без окна: `python -m rvmat_studio kit base.rvmat myhelmet out/` · `python -m rvmat_studio validate file.rvmat`.

> Вес окружения: было ≈ 670 МБ (PySide6), стало ≈ 40 МБ (numpy + Pillow).

## Экспорт — одна кнопка «Экспорт…»

Окно как в Blender: выбираете папку проекта, имя меша и что экспортировать. Результат:

```
<корень проекта>/
└─ <меш>/
   ├─ <меш>.fbx                       ← модель (исходный FBX копируется; OBJ → FBX с исходным масштабом и частями)
   └─ data/
      ├─ <меш>_nohq.paa  <меш>_as.paa  <меш>_smdi.paa  <меш>_co.paa     ← текстуры (PNG/TGA → PAA; готовые .paa копируются)
      ├─ <меш>.rvmat  <меш>_damage.rvmat  <меш>_destruct.rvmat …        ← выбранные RVMAT
      └─ <меш>_<селекшен>[_<пресет>].rvmat, <меш>_<селекшен>_nohq.paa …  ← отдельный набор на каждый материал/селекшен
```

- В RVMAT пути текстур переписываются на `<префикс>\<меш>\data\<файл>.paa` (префикс — путь корня относительно диска P:, можно изменить).
- Выбор RVMAT: основной / `_damage` / `_destruct` / `_decorative` / `_decorative_damage` / `_decorative_destruct`.
- Если материалов несколько (по селекшенам модели), для каждого создаётся свой набор текстур и RVMAT. Имя селекшена берётся из назначенной части или задаётся вручную; имя применённого пресета добавляется в имя RVMAT (кириллица транслитерируется).
- Перед записью показывается дерево файлов, замечания диагностики и существующие файлы; перезапись только по галочке (создаются `.bak`).
- Конвертер PAA: встроенный (numpy; DXT1/DXT5, MIP-уровни, `_nohq` с перестановкой каналов) или `ImageToPAA.exe` из DayZ Tools (рекомендуется для боевых текстур).

## Автозагрузка папки проекта

`Файл → Открыть папку проекта (FBX + data)…` (Ctrl+Shift+O) или `Инструменты → Корень проекта` с папкой меша `<меш>/` (внутри `<меш>.fbx` и `data/`; можно выбрать и родительскую папку):

- подгружается модель, текстуры из `data/`, все `*.rvmat` (состояния base/damage/destruct/decorative… собираются в материалы), селекшены и пресеты восстанавливаются из имён `<меш>_<селекшен>_<пресет>.rvmat`, Base Color — из `_co/_ca`;
- настройки экспорта (папка, префикс, состояния) выставляются так, чтобы повторный «Экспорт…» давал те же файлы;
- если в папке несколько мешей — предложит выбрать; если проект уже изменён — спросит подтверждение; вся загрузка отменяется одним Ctrl+Z.

## Что умеет

- **Backend:** lossless-парсер RVMAT (неизвестные параметры/классы/комментарии сохраняются), модель материала, процедурные текстуры, комплекты из 6 состояний, диагностика.
- **Быстрая настройка:** ползунки «Шероховатость / Сила блика / Металличность / Свечение» пишут реальные поля RVMAT (`specularPower`, `specular`, `diffuse`/`ambient`, `emmisive`); RGBA и шейдеры — в блоке «Подробно». «Сила нормали» — только предпросмотр.
- **Несколько материалов и селекшены:** части модели (группы OBJ, объекты FBX), материал на каждую часть, выбор части кликом по модели.
- **Предпросмотр на видеокарте (OpenGL 3.3, `moderngl`):** тяжёлые модели (проверено на 1 000 000 треугольников) и текстуры 4K/8K — в полном разрешении, мипмапы + анизотропия, сглаживание 4×; вращение, масштаб, 5 схем света, HDRI, режимы просмотра (Base Color, AS, нормали, SMDI-каналы…), сравнение двух состояний, UV-развёртка. Если GPU/OpenGL недоступен — автоматический откат на процессорный рендер (numpy). Выбор: Настройки → «Рендер предпросмотра» или переменная `RVMAT_RENDERER=gl|cpu`.
- **Текстуры:** PNG/TGA/JPG/TIFF/BMP, чтение PAA (DXT1/3/5, ARGB, AI88, LZO), авто-сопоставление `_nohq/_as/_smdi` и `_co`, просмотр каналов.
- **Проект:** undo/redo, история, автосохранение и восстановление, импорт готовых RVMAT, пакетное редактирование, пресеты (12 встроенных + свои).

Горячие клавиши: Ctrl+N/O/S/Shift+S, Ctrl+I импорт RVMAT, **Ctrl+E экспорт**, Ctrl+Z/Y, F2 переименовать, F5 диагностика.

## Честные ограничения

- Предпросмотр — **приближение** шейдера Super, не движок Enfusion (Справка → «Отличия предпросмотра от игры»). GPU-рендер читает готовый кадр обратно в память и показывает его в окне tkinter (вместо встроенного GL-виджета), поэтому обновление зависит ещё и от этой копии. На Windows контекст создаётся через WGL, на Linux — через EGL; **на реальных видеокартах и драйверах Windows не проверялось** (тесты шли на программном Mesa).
- Раскладка `_smdi` (R=1, G=specular, B=specular power), `_as` (затенение в G), `_nohq` (X в альфе, инвертирован) и формулы света взяты из сторонних описаний (BI-вики, экспортёры/реконструкции шейдера), **на движке не проверены**.
- Встроенный кодер PAA проверен только чтением собственным декодером, **не самой игрой** (несжатые MIP-уровни, теги AVGC/MXC/FLAG/OFFS). Для боевых текстур используйте `ImageToPAA`.
- Экспорт FBX из OBJ и копирование FBX проверены только повторным чтением собственным загрузчиком, не Blender/Object Builder. Селекшены P3D не читаются и не пишутся: «часть» — это объект/группа FBX/OBJ.
- Stage3 для обычного (base) материала не подтверждён образцами (взят как у decorative; сообщение `I300`).
- Интеграция с Workbench (`-project=<dayz.gproj>`) не проверялась на реальных DayZ Tools.
- Ограничения tkinter: интерфейс аккуратный, но проще, чем на Qt.

## Тесты

```bash
pip install -r requirements.txt -r requirements-gl.txt pytest
python -m pytest -q                      # ядро; тесты интерфейса пропускаются без tkinter/дисплея
xvfb-run -a python -m pytest -q          # Linux: с интерфейсом и GPU-рендером (apt install python3-tk xvfb libegl1 libgl1-mesa-dri)
RVMAT_RENDERER=cpu xvfb-run -a python -m pytest -q   # то же на процессорном рендере
python -m rvmat_studio --selftest        # окно + рендер + экспорт
```
