# Политика безопасности

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте **Security → Report a vulnerability** (приватное сообщение,
GitHub Security Advisories) в репозитории. Приложите файл-пример (FBX/PAA/OBJ/`.rvproj`/`.rvpreset`/RVMAT),
шаги воспроизведения и версию программы. Ответ — в течение 7 дней; исправление и раскрытие согласуем с вами.

## Поддерживаемые версии

Исправления безопасности выходят для последней версии ветки `main` (сейчас 0.2.x). Старые версии не поддерживаются.

## Что считается уязвимостью

- аварийное завершение, зависание или исчерпание памяти при открытии файла (должна быть понятная ошибка);
- чтение или запись файлов вне разрешённых папок (проект, экспорт);
- запуск программ, которые пользователь не выбирал;
- обход проверок путей/схем через `.rvproj`, `.rvpreset`, RVMAT.

Приложение работает локально и не отправляет данные в сеть.
